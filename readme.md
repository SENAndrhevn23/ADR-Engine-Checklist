## Goal for 0.0.1

The main goal of **ADR Engine 0.0.1** is to create a heavily optimized FNF engine capable of handling extremely large charts while giving the user direct control over how notes are loaded, cached, processed, skipped, culled, and rendered.

> **Performance first.**
>
> The engine should avoid doing work that is not necessary for what the player currently sees or interacts with.
